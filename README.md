# kintone JavaScript カスタマイズ学習リソース

このリポジトリは、kintone の JavaScript カスタマイズについて理解を深めるための学習リソースです。
基本的な知識から応用まで、段階的に学習できるよう構成されています。

## 📚 学習の進め方

### 1. 基礎固め（復習）
まずは基本概念の確認から始めましょう：

- **kintone JavaScript API の基本**
  - `kintone.events` でのイベント処理
  - `kintone.app.record` でのレコード操作
  - `kintone.app.getFieldElements()` でのフィールド取得

### 2. 段階的学習パス

#### 🟢 初級レベル（基本をマスター）
- [ ] フィールド値の取得・設定
- [ ] 基本的なバリデーション
- [ ] シンプルな計算処理
- [ ] フィールドの表示/非表示制御

#### 🟡 中級レベル（実用的なカスタマイズ）
- [ ] 複雑なバリデーションロジック
- [ ] 外部APIとの連携
- [ ] 一括処理とパフォーマンス最適化
- [ ] カスタムビューの作成

#### 🔴 上級レベル（高度なカスタマイズ）
- [ ] プラグイン開発の基礎
- [ ] 複雑なビジネスロジックの実装
- [ ] パフォーマンス最適化技術
- [ ] エラーハンドリングとデバッグ技術

## 🎯 推奨学習順序

1. **[基礎] フィールド操作とイベント処理**
   - examples/basic/ のサンプルを実行
   - 自分の環境で動作確認

2. **[実践] 実際の業務課題を解決**
   - 家計簿の自動計算機能
   - データ入力の効率化

3. **[応用] より複雑な機能の実装**
   - 外部サービスとの連携
   - 複数アプリ間の連携

4. **[発展] パフォーマンスと保守性の向上**
   - コードの最適化
   - テストとデバッグ手法

1. **小さく始める**: 最初は簡単な機能から
2. **実際に動かす**: 必ず手を動かして確認
3. **エラーを恐れない**: エラーから学ぶことが多い
4. **コミュニティを活用**: 開発者フォーラムや勉強会に参加
5. **継続的改善**: 定期的にコードを見直し、改善する
