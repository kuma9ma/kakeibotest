# 練習問題・課題集

このファイルには、kintone JavaScript カスタマイズの理解を深めるための練習問題と課題を掲載しています。
段階的に難易度が上がるよう構成されているので、順番に取り組んでみてください。

## 🟢 初級レベル

### 練習問題 1: 基本的なフィールド操作
**目標:** フィールド値の取得・設定の基本をマスターする

**問題:**
家計簿アプリで以下の機能を実装してください：

1. 「価格」と「数量」フィールドの値が変更されたときに、「合計金額」フィールドを自動計算する
2. 合計金額が1万円を超えた場合、フィールドの背景色を薄い赤色に変更する
3. カテゴリが「食費」の場合、メモフィールドに「食事内容を詳しく記録しましょう」というプレースホルダーを設定する

**ヒント:**
- `kintone.events.on` でフィールド変更イベントを捕捉
- `kintone.app.record.getFieldElement` でDOM要素を取得
- スタイルの変更は `.style.backgroundColor` を使用

### 練習問題 2: バリデーション機能
**目標:** 入力値の検証ロジックを理解する

**問題:**
以下のバリデーションルールを実装してください：

1. 商品名は必須で、20文字以内
2. 価格は1円以上100万円以下
3. 日付は今日から1年前までの範囲内
4. カテゴリが「交通費」の場合、数量は1のみ許可
5. エラーがある場合は保存を中断し、具体的なエラーメッセージを表示

**期待する動作:**
- バリデーションエラー時に保存が中断される
- 複数のエラーがある場合、すべてのエラーが表示される
- エラーメッセージがわかりやすい

### 練習問題 3: 動的UI制御
**目標:** 条件に応じてUIを動的に変更する

**問題:**
以下の動的制御機能を実装してください：

1. カテゴリが「固定費」の場合、数量フィールドを非表示にする
2. 商品名に「定期」が含まれる場合、「次回支払日」フィールドを表示する
3. 金額が5万円を超える場合、確認チェックボックスを表示し、チェックされるまで保存できないようにする

**発展課題:**
- アニメーション効果を追加する
- 条件に応じてフィールドのラベルも変更する

### 練習問題 4: REST API活用
**目標:** kintone REST API を使ったデータ操作を理解する

**問題:**
月次集計機能を実装してください：

1. 「月次集計実行」ボタンをヘッダーに追加
2. ボタンクリック時に、今月のすべてのレコードを取得
3. カテゴリ別の合計金額を計算
4. 結果を別アプリ（月次統計アプリ）に保存

**技術要件:**
- REST API を使用してレコードを取得・作成
- エラーハンドリングを適切に実装
- 処理中はローディング表示を行う

**ヒント:**
```javascript
// レコード取得の例
const response = await kintone.api(kintone.api.url('/k/v1/records', true), 'GET', {
    app: APP_ID,
    query: 'date >= "2024-01-01" and date <= "2024-01-31"'
});
```

## 🏆 学習の進め方
